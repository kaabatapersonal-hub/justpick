# JustPick

Stop thinking. Just pick.

JustPick is a fast, fun PWA that helps you instantly decide 
what to eat or do — based on your mood.

## Features
- Mood-based decision engine
- Food & Activity suggestions
- Daily challenges & streaks
- Group decision mode
- Share result cards
- Dark mode
- Works offline (PWA)

## Built With
- React + Vite
- Firebase (Firestore + Auth)
- Tailwind CSS
- Framer Motion

## Getting Started

```bash
npm install
npm run dev
```
